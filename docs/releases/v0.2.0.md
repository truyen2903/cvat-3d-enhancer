# Meow v0.2.0

## Tải về và cài đặt

1. Tải **meow-v0.2.0.zip** trong mục Assets bên dưới. Không cần tải Source code.
2. Giải nén ZIP, giữ thư mục **meow** ở vị trí cố định.
3. Mở `chrome://extensions` hoặc `brave://extensions`, bật **Developer mode**.
4. Chọn **Load unpacked** → chọn thư mục **meow** chứa `manifest.json`.
5. Với CVAT công ty, mở popup Meow → nhập URL CVAT → **Add & Activate Link**, cấp quyền domain và tải lại tab CVAT.
6. Vào **Settings → Workspace** trong CVAT để bật/tắt từng tính năng.

**Không cần cài Node.js/npm hoặc tự build.** Thư mục cài đặt có sẵn `INSTALL.txt`.

## Thay đổi

- Sidebar tương thích với bố cục CVAT tùy chỉnh; bổ sung đường lấy ObjectState trực tiếp từ sidebar cho H/W/L và đổi hướng.
- Double-click giữ focus gốc của CVAT, có tùy chọn bỏ Quick filter tự động.
- Tia đỏ 1 px bám đáy cuboid ở cả ô Side/Front nhỏ và khi mở rộng.
- WASD/QE nhạy hơn, vẽ lại ngay khi nhấn và lưu khi thả phím.
- Point khung 3D chính lớn hơn 20%, giữ tỷ lệ zoom gốc; Top/Side/Front giữ nguyên.
- Thêm 8 tùy chọn Workspace, tự lưu và áp dụng ngay.

Tương thích tùy thuộc các API nội bộ mà bản CVAT cung cấp. Xem [ghi chú tương thích](https://github.com/truyen2903/cvat-3d-enhancer/blob/main/docs/compatibility.md).

## Cập nhật từ bản cũ

Thay nội dung thư mục extension đã nạp bằng nội dung thư mục `meow` trong ZIP mới, giữ nguyên đường dẫn cài đặt, bấm **Reload** tại trang Extensions rồi tải lại CVAT.
