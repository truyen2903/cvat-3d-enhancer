# Meow v0.2.5

- Add RS beside H/W/L for tracks with mutable ride_state. Apply the current checked or unchecked value throughout the same track without changing geometry or other attributes.
- Wait for native frame loading to finish before camera follow consumes the frame transition; support customized CVAT models with unversioned renderer objects.
- Support native focusAndExpand and updateState callbacks on customized sidebars.
- Remove duplicate perspective canvas.setup processing and avoid processing old clouds during frame transitions.
- Finish empty-filter processing and refresh point colors when the visible track IDs change on the same frame.

Native ObjectState adapters are required for RS. CVAT's Save control persists annotation changes to the server.
